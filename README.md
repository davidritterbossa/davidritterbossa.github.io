## 🌐 Como Publicar Gratuitamente no GitHub Pages

Você pode colocar este site no ar gratuitamente em menos de 5 minutos:

1. **Crie uma conta no GitHub** (se ainda não tiver): [github.com](https://github.com).
2. **Crie um novo repositório**:
   - Clique em **New** / **Novo repositório**.
   - Dê um nome como `portfolio` ou `meu-site` (ou `seunome.github.io`).
   - Deixe o repositório como **Public** (Público).
3. **Envie os arquivos**:
   - Faça o upload dos arquivos `index.html`, da pasta `css/` e da pasta `js/` para o repositório.
4. **Ative o GitHub Pages**:
   - No seu repositório, vá na aba **Settings** (Configurações).
   - No menu lateral esquerdo, clique em **Pages**.
   - Em **Build and deployment** > **Source**, selecione a branch `main` (ou `master`) e a pasta `/ (root)`.
   - Clique em **Save**.
5. **Pronto!** Em cerca de 1 minuto seu site estará disponível na internet no endereço:
   `https://davidritterbossa.github.io/portfolio/`
